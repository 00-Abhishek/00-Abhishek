### 🧠 Learning by Building From Scratch

<p align="center">
  <img src="https://i.pinimg.com/originals/e4/26/70/e426702edf874b181aced1e2fa5c6cde.gif" width="460" alt="From Scratch Implementations" style="border-radius: 8px;">

*Deep understanding is earned by building from bare tensors. These repositories demonstrate architectural implementations without high-level shortcuts:*

<table>
  <tr>
    <td width="50%" valign="top">
      <h4><a href="https://github.com/00-Abhishek/roberta-from-scratch">🔹 RoBERTa Pretraining From Scratch</a></h4>
      <p>Complete pretraining pipeline built end-to-end in PyTorch and Hugging Face. Features a custom 50,000-vocabulary Byte-Level BPE tokenizer, dynamic 15% MLM batch collation, 12-layer RoBERTa encoder (~45M params), random weight initialization, GPU training loop (loss dropped from 15.x to 5.8), and fill-mask inference verification.</p>
      <p><code>PyTorch</code> • <code>Hugging Face Tokenizers</code> • <code>MLM</code> • <code>CUDA</code></p>
    </td>
    <td width="50%" valign="top">
      <h4><a href="https://github.com/00-Abhishek/attention-is-all-you-need-build-the-transformer-from-scratch">🔹 Transformer: Attention Is All You Need</a></h4>
      <p>PyTorch reimplementation of the landmark encoder-decoder Transformer from first principles. Implements sinusoidal positional encodings, multi-head scaled dot-product attention, causal and padding masks, residual layer-norm connections, label smoothing, and Noam learning rate scheduling.</p>
      <p><code>PyTorch</code> • <code>Seq2Seq</code> • <code>Multi-Head Attention</code> • <code>Math Fundamentals</code></p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h4><a href="https://github.com/00-Abhishek/denoising-diffusion-ddpm-from-scratch">🔹 DDPM: Diffusion Models From Scratch</a></h4>
      <p>Clean PyTorch implementation of Denoising Diffusion Probabilistic Models. Covers forward Gaussian diffusion with linear beta schedules, sinusoidal timestep embeddings, time-conditioned neural network noise prediction under MSE loss, and reverse sampling generation.</p>
      <p><code>PyTorch</code> • <code>Generative AI</code> • <code>Diffusion Schedulers</code> • <code>MSE Noise Prediction</code></p>
    </td>
    <td width="50%" valign="top">
      <h4><a href="https://github.com/00-Abhishek/my-VDB">🔹 MyAI: Vector Database From Scratch</a></h4>
      <p>A zero-dependency vector database engine written purely with the Python standard library. Implements HNSW (Hierarchical Navigable Small World), KD-Tree, and Brute Force search algorithms side-by-side with Cosine, Euclidean, and Manhattan metrics, 2D PCA cluster visualization, and a local RAG pipeline via Ollama.</p>
      <p><code>Python StdLib</code> • <code>HNSW Graph Index</code> • <code>Vector Search</code> • <code>Algorithms</code></p>
    </td>
  </tr>
  <tr>
    <td colspan="2" valign="top">
      <h4><a href="https://github.com/00-Abhishek/BackPropagation">🔹 Backpropagation Engine From Scratch</a></h4>
      <p>First-principles neural network and analytical gradient backpropagation engine implemented from scratch in Python, achieving 85% test accuracy on MNIST with custom cross-entropy loss and sigmoid/softmax activations without third-party ML frameworks.</p>
      <p><code>Python</code> • <code>Calculus & Gradients</code> • <code>Neural Networks</code> • <code>MNIST</code></p>
    </td>
